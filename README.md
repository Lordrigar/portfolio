# Portfolio

My personal portfolio website, built with React and Vite.

## Development

Requires Node.js 22.12 or newer.

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm start
```

## Docker

```sh
git pull
docker compose up -d --build
```

The application is available on port 3000. Docker installs dependencies and
builds the frontend automatically.
